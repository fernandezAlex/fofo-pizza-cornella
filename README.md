# Fofó Pizza Cornellà — web conceptual

Landing estática, responsive y accesible creada como propuesta web no oficial para Fofó Pizza, en Cornellà de Llobregat.

## Demo

La web se publica mediante GitHub Pages.

## Contenido

- Carta con 29 productos y filtros accesibles.
- CTA de pedido mediante Uber Eats.
- Dirección, teléfono y horario publicado para pedidos online.
- SEO local y datos estructurados `Restaurant`.
- Diseño sin fotografías de terceros: utiliza composiciones gráficas propias hasta disponer de material autorizado.
- HTML, CSS y JavaScript sin dependencias ni proceso de build.

## Desarrollo local

```bash
python3 -m http.server 8080
```

Después abre `http://localhost:8080`.

## Procedencia y limitaciones

La carta, precios y horario se contrastaron con información pública disponible el 26/07/2026. Pueden cambiar y deben validarse con el negocio antes de convertir esta propuesta en web oficial.

Este repositorio no incluye fotografías descargadas de Google, Uber Eats, directorios o agregadores. Para una publicación comercial definitiva deben utilizarse archivos originales y contar con autorización de uso.

## Estado del proyecto

Propuesta conceptual para revisión. No representa una web oficial de Fofó Pizza y no implica relación comercial con el negocio.
