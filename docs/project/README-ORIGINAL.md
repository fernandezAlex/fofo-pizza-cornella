# Fofó Pizza · sitio web

Sitio estático responsive para una pizzería de Cornellà, construido con HTML, CSS y JavaScript sin dependencias de build.

## Archivos

- `index.html`: toda la estructura, estilos y comportamiento.
- `assets/`: fotografías locales usadas por la página.
- `INVESTIGACION.md`: fuentes y decisiones de contenido.
- `DESIGN_AUDIT.md`: auditoría visual inicial.
- `fofo-pizza-web.zip`: paquete listo para entregar.

## Abrir en local

Puedes abrir `index.html` directamente o servir la carpeta con:

```bash
python3 -m http.server 8080
```

Después visita `http://localhost:8080`.

## Incluye

- Portada fotográfica y navegación responsive.
- Sección de posicionamiento y proceso.
- Carta filtrable por categorías.
- Producto destacado.
- Galería fotográfica.
- Dirección, teléfonos, servicios y horario orientativo.
- Accesos a llamada, Maps y Uber Eats.
- JSON-LD de tipo `Restaurant`.
- Aviso de alérgenos y advertencia sobre horarios.

## Validación original

La entrega inicial comprobó la carga de las siete imágenes, la navegación, los filtros y los enlaces principales.
