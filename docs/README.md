# Documentación del proyecto

Este directorio organiza la información producida durante el trabajo en Hermes Kanban para que futuros agentes puedan reconstruir el contexto sin depender de la base de datos interna de Hermes.

## `research/`

- `INVESTIGACION-INICIAL.md`: investigación utilizada para crear la primera versión.
- `INVESTIGACION-AMPLIADA.md`: documento adjunto a Kanban con investigación y verificación posterior más extensa.
- `FUENTES-Y-DECISIONES-POSTERIORES.md`: fuentes y decisiones editoriales preparadas durante una revisión posterior.

## `brand/`

- `README.md`: preparación del logo transparente y paleta corporativa rojo/verde.
- `logo-source-user.png`: archivo de identidad visual aportado por Alex.

## `kanban/`

Exportaciones textuales de las tareas originales, conservando cuerpos, comentarios, estados, dependencias y resultados:

1. `00-proyecto-raiz.md`
2. `01-investigacion.md`
3. `02-auditoria-visual.md`
4. `03-especificacion-ux-contenido.md`
5. `04-implementacion.md`
6. `05-validacion.md`

La exportación permite entender decisiones contradictorias entre fases. La petición final del propietario es preservar la versión original sin cambios visuales.

## `project/`

- `README-ORIGINAL.md`: instrucciones de la entrega inicial.
- `PRESERVACION.md`: relación entre la web canónica y la documentación.

## Criterio para agentes

Lee primero `../AGENTS.md`. La documentación se conserva como evidencia y contexto; no debe interpretarse automáticamente como una orden para alterar la web publicada.
